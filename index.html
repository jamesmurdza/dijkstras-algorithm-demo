# Find the shortest (weighted) paths from start to all other nodes
def dijkstra(nodes: list[Node], start: Node) -> dict[Node, float]:
    # All nodes, and our distance estimates
    distances = {node: float("inf") for node in nodes}
    distances[start] = 0
    # The nodes we've visited already
    unvisited = set(nodes)

    while unvisited:
        # u is the node we're visiting
        u = min(unvisited, key=lambda node: distances[node])
        unvisited.remove(u)

        # v is each neighbor of u
        for v in u.neighbors:
            if v in unvisited:
                # Relax the edge between u and v
                new_distance = distances[u] + weight(u, v)
                distances[v] = min(distances[v], new_distance)

    # All distances are now correct
    return distances

Dijkstra's algorithm finds the shortest distance from a single start node to every other node in a weighted graph.

It starts by assuming every node is unreachable (distance infinity) except the start node, which is distance zero. Every node begins unvisited.

Then it repeats one step until every node has been visited: among the unvisited nodes, pick the one with the smallest known distance, and mark it visited. That distance is now final - it can never improve later.

For every neighbor of the node just visited, check whether going through it gives a shorter path than what that neighbor currently has on record ("relaxing" the edge). If so, update the neighbor's distance and remember this node as the way to reach it.

Once every node has been visited, every distance is guaranteed correct, and retracing each node's recorded predecessor back to the start gives its shortest path.
